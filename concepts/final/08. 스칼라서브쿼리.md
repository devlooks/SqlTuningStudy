고급 조인 기법
  - 인라인 뷰 활용 -> 1:M -> M쪽을 그룹핑 -> 건수 줄임 -> 조인시 조인 횟수도 줄임
  - 배타적인 관계 조인
```
select ~
from 작업지시 a, 개통신청 b, 장애건수 c
where a.~ between ~ and ~
and b.개통신청번호(+) = a.개통신청
and c.장애접수번호(+) = a.개통신청

또는 Union all 1, 2로 분기 처리 -> 단 인덱스 필요, 인덱스 있어야 중복 스캔 X
```
