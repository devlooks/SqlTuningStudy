Union ALL 이용한 M:M 조인
  - Full Outer Join 대체 용도 -> Union all 활용
  - Full Outer Join -> 테이블 두번 접근, Union all이용 중복 스캔 제어 가능
  ```
  select '실적' as 구분 ~
  union all
  select '계획' as 구분 ~
  
  select ~
  from (
        select ~
        union all
        select ~
      )
  group by ~
  ```

페이징 
  - 일반 적인 페이징
```
pgsize -> 10, page -> 3

select *
from (
      select rownum no
            , ~
            , count(*) over() cnt -> 다음페이지 유무 확인

      from (
            select ~
            from 시간별 종목 거래
            where 종목코드 = :~
            and 거래일시 >= :~
            order by 거래일시 -> 종목코드 + 거래일시 -> index 구성 -> sort 생략 목적
      )
      where rownum < :page * pgsize + 1
)
where no between(:page - 1) * :pgsize + 1 and :pgsize * :page
```

윈도우 함수 활용
  - 장비 측정 결과 조회 -> 상태코드 Null -> 가장 최근 상태코드
```
  ex1)
  select 일련번호, 측정값
         ,(select (max(상태코드)
            from 장비측정
            where 일련번호 <= o.일련번호
            and 상태코드 is not null)) 상태코드 -> 인덱스 구성
  from 장비측정 o
  order by 일련번호

  ex2)
  select ~
      , (select /*+ index_desc(장비측정 장비측정_idx) */ 상태코드
         from 장비측정 ~
  from 장비측정 o

  ex3)
  select 일련번호, 측정값
      , last_value(상태코드 ignore nulls)
        over(order by 일련번호 rows between unbounded preceding and current row) 상태코드
  from 장비측정
  order by 일련번호
```
