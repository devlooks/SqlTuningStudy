쿼리 변환
  - 의미 동일 -> 나은 성능 기대 형태로 재작성
    - 휴리스틱 쿼리 변환 -> 규칙 기반
    - 비용 기반 쿼리 변환 -> 비용 기반

  - 서브쿼리 Unnesting(Sub Query Flattening)
    - 중첩 서브쿼리를 풀어내는 것
    - 중첩 서브쿼리 -> 조인 문 변환
    - 서브쿼리 Unnesting X -> 서브쿼리 -> filtering
      - 메인 쿼리의 건수를 건건히 처리
    - Unnesting -> 성능 보장 하지 않음
      - /*+ unnest */
      - /*+ no_unnest */
     
  - 서브쿼리가 M 또는 Nonunique Index 일 경우
    - 메인 쿼리 1, 서브쿼리 M 관계 -> M 기준 집합 생성 -> 오류
    - 메인 쿼리 M, 서브쿼리 1 관계 -> 오류 X
   
    - 1쪽 집합 확신 할 수 없는 서브 쿼리의 테이블 드라이빙
      - Sort Unique 오퍼레이션 수행 -> 1쪽 집합으로 만든 후 조인
     
    - 메인 쿼리쪽 테이블 드라이빙 -> Semi join 방식으로 조인
    - NL 세미조인 -> 수행 -> sort unique 수행X -> M 쪽 집합 확장 방지
   
뷰 Merging 
  - 서브 쿼리 조인시 메인 테이블 레벨로 서브 쿼리 테이블을 올려서 조인
    - 오히려 성능이 떨어질 수 있음(복잡한 연산 포함시)
    - ex) group by, select-list + distinct
   
  - 뷰 Merging 불가능 케이스
    - 집합연산자 (union, union all, intersct, minus)
    - connect by
    - rownum pseudo 컬럼
    - select-list -> 집계함수(avg, count, max, min, sum)
    - 분석 함수
    - no_merge 힌트

조건절 pushing
  - 뷰 참조 쿼리 블록의 조건을 뷰 쿼리 블록 안으로 밀어 넣는 기능 -> 조건절이 가능한 빨리 처리
  - 조건절 pushdown : 쿼리 블록 밖의 조건절을 쿼리 블록 안으로
  - 조건절 pullup : 쿼리 블록 밖으로 조건절 이동
  - 조인 조건 pushdown : nl 조인 수행중 드라이빙 테이블에서 읽은 값을 건건히 inner 쪽 뷰 쿼리 블록 안으로 밀어넣기

조건절(Predicate) PushDown
  - 실행 계획의 View 내부에 밖의 조건절 Index를 타게 되는경우
  ```
    select ~ from () a, dept b where a.deptno = b.deptno and b.deptno = 30
  
    View
      Sort Group by
        TA ~ a 테이블
          Index Range Scan -> View 외부조건절의 인덱스 ( b테이블의 deptno 의 인덱스)
  ```

  조건절 Pull up
    - 쿼리 블록 안의 조건절을 밖으로 이동

    ```
    select * from 
        (select ~ from emp where deptno = 10 group by deptno) e1
        ,(select ~ from emp group by deptno) e2
        where e1.deptno = e2.deptno

    View 
        ~
        TA -> emp
          Index Range Scan -> emp_deptno_idx  ->> deptno = 10 
    View
        ~
        TA -> emp
          Index Range Scan -> emp_deptno_idx  ->> deptno = 10 -> e2 View에 deptno = 10 이라는 조건절넣음
    ```

조인 조건 PushDown
  - 조인 조건절을 뷰 쿼리 블록 안으로 밀어 넣음
  ```
  select ~ from dept d
        ,(select /*+ no_merge push_pred */ deptno
          from emp group by deptno) e
  where e.deptno(+) = d.deptno -> View Pushed Predicate (실행계획)
  ```
  - 부분 범위 처리 가능
  - 부분 처리 방법
    - 스칼라 쿼리 사용
    ```
    select ~
      ,(select avg(sal) from emp where ~)
    from dept d
    ```
    - substr 함수 분리
    ```
    select
      ~
      , to_number(substr(sal, 1, 7)) as avg_sal
      , to_number(substr(sal, 8, 7)) as min_sal
      , to_number(substr(sal, 15)) as max_sal
    from (
        select /*+ no_merge */
          ,(select lpad(avg(sal), 7)||lpad(min(sal), 7)||lpad(max(sal), 7) ~ 
    ```

조건절 이행
  - A = B -> B = C -> A = C
  ```
    select * from ~
    where ~
    and a.deptno = 10
    and a.deptno = e.deptno  -> a.deptno = 10, e.deptno = 10
  ```

불필요한 조인 제거
  - OR 조건 -> Union 으로 변환
  - 각각 인덱스 사용 목적 union all
  - OR-Expansion -> 옵티마이저가 union all 로 변환
    - 실행 계획 -> concatenation
  - 중복 액세스 -> 비효율 발생 주의
  - 힌트 -> use_concat, no_expand

기타 쿼리 변환
  - Intersect, Minus 같은 연산 -> Join 으로 변환
  - 조인 컬럼에 is not null 조건 추가
    - 조인 컬럼 null -> 조인 액세스 불필요 -> 조인 실패
    - 테이블 액세스 및 조인 시도줄임 -> 성능 향상
      ```
      select ~
      from emp e, dept d
      where d.deptno = e.deptno
      and d.deptno is not null
      and e.deptno is not null
      ```
  - 필터 조건 추가
    - A between :min and :max
      - max -> 5, min -> 1000 -> 공집합 -> 비효율(비합리적) -> 선택도가 높은 조건부터 평가 하도록 수행
