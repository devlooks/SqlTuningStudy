데이터 베이스 Call 최소화
  - Parse Call : SQL 파싱
  - Execute Call : SQL 실행
  - Fetch Call : select 결과 전송 요청 call
  - User Call : DBMS 외부 요청 Call
    - User Call 줄이기
      - loop Call 줄이고 One SQL
      - Array Processing
      - 부분 범위 처리
      - 효과적 화면 페이징
      - 사용자 정의함수, 프로시저, 트리거, 적절한 활용
     
    - Recursive Call : DBMS 내부 Call
      - 줄이기 -> Bind 변수 사용, 하드파싱 줄이기

  - Fetch Call 줄이기
    - 부분범위처리 : Fetch Call 있을때마다 나눠 전송
    - ArraySize 조정 -> 총량을 줄이지 않고, Fatch Call을 줄이기, 단, ArraySize가 일정 크기 이상이 되면, 오히려 리소스 낭비 발생
   
  - 페이징 처리 활용
    - Fetch Call 을 낮춤
    - 페이지 단위 -> 네트워크 결과 전송
    - 최소량 I/O (인덱스 + 부분범위 처리)
    - 데이터 소량 나누어 전송 AP 웹 리소스 사용량 줄임

  - 사용자 정의 함수, 프로시저 특징/성능
    - 사용자 정의 함수/프로시저
      - 콘텍스트 스위칭 내장함수에 비해 성능 저하
      - 내장 쿼리 수행 Execute Call, Fetch Call 재귀 호출
      - User Call에 비해 성능은 좋지만 Recursive Call이 계속 발생 -> 성능 저하 원인
    - 되도록이면 One SQL 처리(성능 좋은)
