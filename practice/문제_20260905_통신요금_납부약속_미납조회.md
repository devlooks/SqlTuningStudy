# 【문제】 미납 청구 중 납부약속 등록 건 추출

- 출제일 : 2026-09-05
- 배점 : 100점 ([1] 병목 지점 판단 40점 + [2] 개선 SQL 작성 60점)
- 제한시간 : 25분

---

## 1. 업무 요건

**일 배치**로 2026년 8월분 청구 중 **미납 상태(STAT_CD='N')** 이면서
**납부약속이 등록된 건(PRM_STAT='Y')** 만 추출하여 가입 정보·고객 정보와 함께 담당 부서로 전달한다.
현재 **약 14분** 소요.

## 2. 테이블 현황

| 테이블 | 별칭 | 건수 | 블록당 행수 | 비고 |
|---|:---:|---:|:---:|---|
| TB_BILL | B | 60,000,000 | 50 | 청구. 해당 월 미납 건 10만건 |
| TB_SUBSCR | S | 10,000,000 | 50 | 가입 마스터 |
| TB_CUST | U | 8,000,000 | 50 | 고객 마스터 |
| TB_PROMISE | P | 30,000,000 | 50 | 납부약속 이력. 청구건당 평균 1.05건<br>**미납 10만건 중 약속 등록 건은 약 3%** |

## 3. 기존 인덱스

```sql
CREATE UNIQUE INDEX PK_BILL    ON TB_BILL    (BILL_NO);
CREATE        INDEX IDX_BILL_01 ON TB_BILL   (BILL_YM, STAT_CD);
CREATE UNIQUE INDEX PK_SUBSCR  ON TB_SUBSCR  (SUBSCR_NO);
CREATE UNIQUE INDEX PK_CUST    ON TB_CUST    (CUST_ID);
CREATE        INDEX IDX_PRM_01 ON TB_PROMISE (BILL_NO);
```

- TB_BILL.SUBSCR_NO → TB_SUBSCR.SUBSCR_NO (FK, NOT NULL)
- TB_SUBSCR.CUST_ID → TB_CUST.CUST_ID (FK, NOT NULL)
- TB_PROMISE.BILL_NO, TB_PROMISE.PRM_STAT 모두 NOT NULL
- TB_PROMISE 는 TB_SUBSCR / TB_CUST 와 직접 조인 조건이 없음

## 4. AS-IS SQL

```sql
SELECT B.BILL_NO
     , B.BILL_YM
     , B.BILL_AMT
     , S.SUBSCR_NO
     , S.SVC_NM
     , U.CUST_NM
  FROM TB_BILL   B
     , TB_SUBSCR S
     , TB_CUST   U
 WHERE B.BILL_YM  = '202608'
   AND B.STAT_CD  = 'N'
   AND S.SUBSCR_NO = B.SUBSCR_NO
   AND U.CUST_ID   = S.CUST_ID
   AND EXISTS ( SELECT 1
                  FROM TB_PROMISE P
                 WHERE P.BILL_NO  = B.BILL_NO
                   AND P.PRM_STAT = 'Y' );
```
