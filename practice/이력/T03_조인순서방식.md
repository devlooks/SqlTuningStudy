## 2. 출제 완료 · 미풀이 문항

> 출제는 끝났으나 아직 풀지 않은 문항이다. 풀고 나면 §1로 옮기고 이 절에서 지운다.

### 조인 방식 보강 드릴 문항 4·5 (보완판, 2026-09-26)

- **용도:** 보강 드릴 (슬립 #23·#24 확인). 게이트 판정 근거 아님
- **공통 규칙:** 신규 인덱스 0개, 구조 변경 불가, 모든 조인은 등치 조인. K18·K19(09-26 개정)를 따른다

**확정 답안 양식**

```text
① Outer (먼저 읽는 테이블) = ______
   건수 = 실행계획 Id ___ 의 A-Rows ______
          (실행계획이 없으면 문제 본문의 "조건 적용 후 건수")
   ※ SQL이 N건에서 멈추면(Top-N) 실제로 조인까지 가는 건수 = ______
② Inner (나중에 붙이는 테이블) = ______
   FULL 블록 수 = 문제의 테이블 표 → 블록 수 ______      ※ 실행계획은 보지 않음
   조인키로 시작하는 인덱스: 있음(이름 ______) / 없음
③ 손익분기 Outer 건수 = ② 블록 ______ ÷ 4 = ______ 건
④ 비교  NL ≈ ① 건수 ______ × 4 = ______   vs   HASH ≈ ② 블록 ______
⑤ 결과를 어떻게 쓰는가 (하나 선택): 전부 사용 / 앞의 N건만 사용
⑥ 선택 (하나 선택): NL / HASH   근거: ① ___건 vs ③ ___건
```

**문항 4 — 고객 주문 목록 첫 화면 (온라인)**

| 테이블 | 건수 | 블록 수 | 인덱스 |
|---|---:|---:|---|
| ORDERS | 3,000,000 | 30,000 | `ORD_CUST_DT_IX (CUST_ID, ORD_DT)` |
| PRODUCT | 800,000 | 16,000 | `PRODUCT_PK (PROD_ID)` 높이 3 |

```sql
SELECT *
  FROM (SELECT O.ORD_NO, O.ORD_DT, P.PROD_NM
          FROM ORDERS O, PRODUCT P
         WHERE O.CUST_ID = :cust_id
           AND P.PROD_ID = O.PROD_ID
         ORDER BY O.ORD_DT DESC)
 WHERE ROWNUM <= 20;
```

- 이 고객의 주문 전체 6,000건. 주문 1건에 상품 1건. `ORD_CUST_DT_IX` 역순 스캔으로 정렬 없이 최근 주문부터 나온다.

**문항 5 — 캠페인 대상자 이용내역 추출 (배치)**

| 테이블 | 건수 | 블록 수 | 인덱스 |
|---|---:|---:|---|
| CAMPAIGN_TARGET | 50,000 | 500 | `CT_CAMP_IX (CAMP_ID)` |
| USAGE_LOG | 2,000,000 | 20,000 | `UL_DT_IX (USE_DT)` 높이 3 — 이 인덱스 하나뿐 |

```sql
SELECT T.CUST_ID, U.USE_DT, U.USE_AMT
  FROM CAMPAIGN_TARGET T, USAGE_LOG U
 WHERE T.CAMP_ID = :camp_id          -- 대상자 500명
   AND U.CUST_ID = T.CUST_ID;        -- 기간 조건 없음, 전체 이용내역
```

- 배치 추출이며 결과를 전부 사용한다.

**정답 (채점용 · 사용자 비공개)**

- **문항 4:** Outer ORDERS, 부분범위 + 인덱스 정렬로 Stopkey 가능 → ① = **20건**(6,000 아님, K19). Inner PRODUCT 16,000블록, PK 있음. 손익분기 4,000. NL 20 × 4 = 80 vs 16,000 → **NL**. 함정: 6,000을 넣으면 6,000 > 4,000 → HASH로 오판. 힌트 예 `LEADING(O P) USE_NL(P) INDEX_DESC(O ORD_CUST_DT_IX)`
- **문항 5:** Outer CAMPAIGN_TARGET 500건. Inner USAGE_LOG 20,000블록, **조인키(CUST_ID) 선두 인덱스 없음** → K18 예외: NL = 500 × 20,000 = 10,000,000 vs HASH 20,000 → **HASH**. 함정: 500 < 5,000(손익분기)만 보고 NL 선택. 힌트 예 `LEADING(T U) USE_HASH(U) FULL(U)`
