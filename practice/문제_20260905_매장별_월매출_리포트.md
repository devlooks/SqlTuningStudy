# 【문제】 매장별 월 매출 리포트 추출

- 출제일 : 2026-09-05
- 배점 : 100점 ([1] 병목 지점 판단 40점 + [2] 개선 SQL 작성 60점)
- 제한시간 : 25분

---

## 1. 업무 요건

**월 배치**로 영업 중인 전 매장의 2026년 8월 **정상 매출액**과 **취소 건수**를 한 줄씩 뽑아 리포트로 전달한다.
현재 **약 22분** 소요.

> ⚠️ 당월 매출이 **한 건도 없는 매장**(신규 개점, 휴점 등 약 200개)도 리포트에 반드시 포함되어야 하며,
> 이 경우 매출액과 취소건수는 **0** 으로 표기한다.

## 2. 테이블 현황

| 테이블 | 별칭 | 건수 | 비고 |
|---|:---:|---:|---|
| TB_STORE | S | 5,000 | 매장 마스터. 영업중(OPEN_YN='Y') 3,000개 |
| TB_SALES | A | 200,000,000 | 매출. 2026년 8월분 500만건<br>STAT_CD 분포 : 'C'(정상) 90% / 'X'(취소) 10%<br>매장당 월평균 1,667건 |

## 3. 기존 인덱스

```sql
CREATE UNIQUE INDEX PK_STORE     ON TB_STORE (STORE_ID);
CREATE        INDEX IDX_SALES_01 ON TB_SALES (SALE_YM, STORE_ID);
```

- TB_SALES.STORE_ID → TB_STORE.STORE_ID (FK, NOT NULL)
- SALE_YM, STAT_CD, SALE_AMT 모두 NOT NULL

## 4. AS-IS SQL

```sql
SELECT S.STORE_ID
     , S.STORE_NM
     , ( SELECT SUM(A.SALE_AMT)
           FROM TB_SALES A
          WHERE A.SALE_YM  = '202608'
            AND A.STORE_ID = S.STORE_ID
            AND A.STAT_CD  = 'C' )  AS NORMAL_AMT
     , ( SELECT COUNT(*)
           FROM TB_SALES A
          WHERE A.SALE_YM  = '202608'
            AND A.STORE_ID = S.STORE_ID
            AND A.STAT_CD  = 'X' )  AS CANCEL_CNT
  FROM TB_STORE S
 WHERE S.OPEN_YN = 'Y';
```
